# 大明职官图

以山川舆图、府州县辖属、中央官署与人物履历探索明代职官。时间范围为1368—1644年，默认展示1566年；桌面与手机使用不同的浏览布局。

## 功能

- 天下地图、省府州县逐级导航、官署与职官上下级关系。
- 年份与年号切换，人物、官职搜索，任职变化与资料出处。
- 朝堂及州县衙署场景，按所选年份显示对应人名。
- 手机独立导航、全屏阅读弹框与可见视口适配。
- 真实访问计数，以及需要登录的访问分析与反馈管理后台。
- 前台手机号反馈，可附带页面位置和历史年份。

## 本地开发

使用 Node.js 22.13 或更新版本，保留仓库内的 `package-lock.json`。

```sh
npm ci
npm run dev:nas
```

开发地址为 `http://127.0.0.1:5174`。历史内容优先读取仓库内的版本化公开快照；访问统计、反馈和后台还需要 PHP 8.2、PDO MySQL、MySQL 8.0 及独立的私有配置。开发代理指向 `127.0.0.1:8088`。

## 构建与部署

```sh
npm run build:nas
```

将 `dist-nas/` 内部文件部署到网站根目录。当前正式部署目标为用户指定的虚拟主机；不使用 GitHub Pages 承载 PHP/MySQL 服务。原 NAS 方案保留在 `nas/`，完整部署记录见 [DEPLOYMENT.md](DEPLOYMENT.md)。

数据库配置、会话及离线 IP 库位于主机网站根目录之外的 `others/` 目录。部署工具通过隐藏输入接收密码，不将密码放入仓库。后台和手机号反馈需要有效 HTTPS。

```sh
npx tsc --noEmit
node scripts/check-mobile.mjs
node scripts/check-dialog-css.mjs
```

最后一项直接检查构建后的弹框 CSS，需先完成构建。PHP/MySQL 集成检查见 `scripts/test-ops.py`；其测试数据与正式访问、反馈数据隔离。

## 目录与资料

| 目录 | 内容 |
| --- | --- |
| `app/`、`components/`、`hooks/`、`lib/` | 前台页面、交互与数据匹配 |
| `public/api/` | PHP 接口及公开历史读取快照 |
| `public/admin/` | 访问分析、反馈处理与管理员登录 |
| `public/data/`、`research/` | 历史整理资料、官制关系与出处 |
| `scripts/` | 数据整理、隔离检查、构建和发布工具 |

历史人物、任职与官制资料持续校订，当前收录不代表全体明代官员的完整逐年名册。资料出处与第三方许可见 [历史数据来源说明](public/data/history-provenance.html)；保留原始来源及必要的不确定性，不以影视或小说替代史实。

私有凭据、正式访客 IP、手机号反馈、数据库备份、依赖目录及本地构建产物均不在本仓库中。部分历史重建脚本还依赖本地原始资料目录和数据库导出，不能把本仓库视为正式数据库备份。
